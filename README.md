# 🔥 V9 Bot — بوت ديسكورد احترافي

بوت ديسكورد عربي متكامل (سلاش كوماند 100%) بثيم أحمر، أقوى من برو بوت ومبني بالكامل من الصفر.

## ✅ المميزات

### 🛡️ الحماية (Anti System)
| الأمر | الوصف |
|------|-------|
| `/antispam` | منع السبام مع تحديد العقوبة (اخمات/تحذير/طرد/حظر) |
| `/antilink` | منع الروابط نهائياً |
| `/antiinvite` | منع دعوات السيرفرات (discord.gg) |
| `/badwords` | فلترة كلمات ممنوعة (إضافة/حذف/عرض/تفعيل) |
| `/ghostping` | كشف القوست بنق (حذف رسالة فيها منشن) |
| `/antiraid` | حماية من ريد الدخول الجماعي |
| حماية المينشن | حجب الإفراط في عمل مينشن تلقائياً |

## ⚙️ طريقة التشغيل

### 1️⃣ تجهيز البوت في Developer Portal
1. ادخل إلى https://discord.com/developers/applications
2. أنشئ تطبيق جديد وخذ الـ **TOKEN** و **Client ID**
3. من قسم **Bot** فعّل هذه الـ Intents:
   - ✅ **Server Members Intent**
   - ✅ **Message Content Intent**
   - ✅ **Presence Intent**

### 2️⃣ إعداد المشروع
عدّل `config.json`:
```json
{
  "token": "توكن البوت",
  "clientId": "ايدي البوت",
  "owners": ["ايدي حسابك"],
  "color": "#E60000",
  "colorDark": "#8B0000",
  "devGuildId": ""
}
```
> 💡 لو كتبت `devGuildId` = ايدي سيرفرك، الأوامر تظهر فوراً. اتركها فارغة للأوامر العامة (تستغرق ساعة).

### 3️⃣ التشغيل
```
npm install
npm start
```
لاول مرة استخدم `node src/utils/registerCommands.js` لتسجيل الأوامر.

### 4️⃣ إعداد السيرفر
بعد ما يشتغل البوت، استخدم:
- `/setup logs #قناة` — قناة اللوج
- `/setup modlog #قناة` — سجل الإدارة
- `/setup welcome #قناة` — الترحيب
- `/setup leave #قناة` — الوداع
- `/setup autorole @رول` — الرول التلقائي
- `/setup modrole @رول` — رول الإدارة
- `/setup ticket` + `/setup ticketpanel` — نظام التذاكر
- `/setup levelroles` — رولات المستويات
- `/settings` — عرض الإعدادات
- `/antispam on` `/badwords add كلمة` `/ghostping on` ... وهكذا

## 📂 هيكل المشروع
```
index.js                    — نقطة التشغيل
config.json                 — الإعدادات
data/                       — قاعدة البيانات (JSON)
src/
├── handlers/               — تحميل الأوامر والأحداث
├── utils/                  — قاعدة البيانات، الإيمبيد الأحمر، الدوال
├── services/               — التذاكر، القيف أوايز، اللوج
├── commands/               — الأوامر حسب الفئة
└── events/                 — كل أحداث اللوج
```

## 🎨 الثيم الأحمر
كل الإيمبيدات تُرسل بلون أحمر (#E60000) مع **لوجو السيرفر** في الثمبنيل والفوتر، وبصمة الوقت تلقائياً — زر F12 للتخصيص من `config.json`.
